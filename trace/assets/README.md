# Static assets

| Path | Use |
|------|-----|
| `brand/logo.svg` | Sidebar / favicon |
| `brand/logo-large.svg` | Marketing / large placements |
| `brand/loading.gif` | Boot splash animation |

The web app serves a copy under `web/public/assets/brand/` as `/assets/brand/*`.
When updating brand files, copy them into both directories.
