# Support

Use the channel that matches the request:

- **Integration questions and design ideas:** [GitHub Discussions](https://github.com/laststate/trace/discussions).
- **Bugs and scoped feature requests:** [GitHub Issues](https://github.com/laststate/trace/issues).
- **Security vulnerabilities or sensitive captured data:** follow [SECURITY.md](SECURITY.md) and use private vulnerability reporting.
- **Conduct concerns:** use the private process in [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

When asking for help, include the deployment type (self-hosted Docker, Helm/K8s, or SaaS), the Trace version, the backend database type (PostgreSQL, Redis, NATS), and the smallest reproducible behavior. Remove secrets, private endpoints, device identifiers, and captured customer memory.

The maintainer target is to acknowledge new issues and pull requests within 72 hours and triage them within seven days. This is not a commercial support SLA.

Self-hosting and operations questions should reference [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md) and [docs/SELF_HOSTING.md](docs/SELF_HOSTING.md).

## Commercial support

- **Free / Hobbyist**: Community support via GitHub Issues.
- **Team**: Priority support via GitHub Issues with 72-hour response target.
- **Enterprise**: Dedicated support with 4-hour response SLA, direct Slack channel, and quarterly reviews. Contact [sales@laststate.dev](mailto:sales@laststate.dev).
