1. Get the application URL by running these commands:
  kubectl get ingress {{ include "billing-service.fullname" . }}

2. Check the health endpoint:
  curl http://$(kubectl get ingress {{ include "billing-service.fullname" . }} -o jsonpath='{.spec.rules[0].host}')/health

3. View pods:
  kubectl get pods -l app.kubernetes.io/name={{ include "billing-service.name" . }}

If you see connection errors to PostgreSQL, ensure the database is ready:
  kubectl get pods -l app.kubernetes.io/name=postgres
