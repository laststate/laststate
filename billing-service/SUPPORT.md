# Support

Use the channel that matches the request:

- **Integration questions and design ideas:** [GitHub Discussions](https://github.com/laststate/billing-service/discussions).
- **Bugs and scoped feature requests:** [GitHub Issues](https://github.com/laststate/billing-service/issues).
- **Security vulnerabilities or sensitive payment data:** follow [SECURITY.md](SECURITY.md) and use private vulnerability reporting.
- **Conduct concerns:** use the private process in [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

When asking for help, include the payment provider (Stripe, Mercado Pago, or Crypto), the plan tier, the specific error, and the steps to reproduce. Remove secrets, API keys, customer PII, and production endpoint credentials.

The maintainer target is to acknowledge new issues and pull requests within 72 hours and triage them within seven days. This is not a commercial support SLA.

## Commercial support SLA

| Tier | Response time | Availability | Channels |
|------|--------------|--------------|----------|
| **Free / Hobbyist** | Best-effort | Community | GitHub Issues |
| **Team** | 72 hours | Business hours | GitHub Issues + Email |
| **Enterprise** | 4 hours | 24/7 | Dedicated Slack + Phone + Email |

Enterprise support includes:
- Dedicated account manager
- Quarterly business reviews
- Custom integration assistance
- Priority bug fixes
- SLA-backed incident response

Contact [sales@laststate.dev](mailto:sales@laststate.dev) for Enterprise support inquiries.
